# RAM 🐏

A tiny macOS menu extra that shows memory pressure and who is hogging all the RAM.

This app is heavily inspired by [Stats](https://github.com/exelban/stats), which
cover CPU, GPU, disks, network, sensors, batteries, and a feature fetched
settings window, **you should probably use it instead.**

Anyone with Xcode can build and run it. See [Getting started](docs/getting-started.md).
